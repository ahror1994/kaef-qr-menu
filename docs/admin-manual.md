# Инструкция администратора

Вход: `https://<ваш-домен>/admin/login`. Верхнее меню — разделы админки.

## Разделы

### Блюда (`/admin/menu`)
- Фильтр по категориям, кнопка «+ Добавить блюдо».
- Поля: категория, название, описание, цена, вес, URL изображения, флаги
  «Показывать в меню» и «Метка NEW», тип карточки (с фото / строковая —
  «название …… цена вес», как в оригинальном меню).
- Изменение/удаление — кнопками в строке. Изменения сразу видны гостям.

### Категории (`/admin/categories`)
- Название, slug (латиницей — используется в адресе-якоре, например `#osnovnaya`),
  порядок сортировки, видимость. Удаление категории удаляет её блюда.

### Медиа (`/admin/media`)
- Загрузка изображений (до 10 МБ, jpg/png/webp/gif/svg/avif).
- «Копировать URL» — вставьте скопированный адрес в поле «URL изображения»
  у блюда или в настройках логотипа. Удаление файла убирает его с сайта.

### Метки (`/admin/labels`)
- Бейджи карточек (NEW, HIT…): название + иконка. Управляется отдельно от блюд.

### Настройки (`/admin/settings`)
- **Общие**: название сайта, meta description, URL логотипа.
- **Футер**: копирайт, год (по умолчанию 2026), адрес, телефон, часы работы,
  произвольные ссылки и соцсети (кнопками «+ Ссылка» / «+ Соцсеть»).
  Всё, что отображается в футере, редактируется здесь без правок кода.

### Импорт / Экспорт (`/admin/import-export`)
- **Экспорт** — скачать полный JSON меню, меток и настроек (бэкап контента).
- **Импорт** — загрузить JSON. Перед импортом выбирается режим:
  «объединить» (обновить/добавить) или «заменить» (сначала удалить всё меню).
  Доступно только ADMIN.

### Пользователи (`/admin/users`, только ADMIN)
- Создание редакторов (EDITOR) и администраторов (ADMIN), включение/отключение,
  смена пароля, удаление. Пароль — минимум 10 символов.

### Журнал (`/admin/audit-log`)
- Кто, когда и что менял: создание/изменение/удаление блюд, категорий, настройки,
  загрузки и импорты.

## Частые операции

- **Сменилось блюдо**: Блюда → Изменить → правки → Сохранить.
- **Блюдо временно недоступно**: снимите флажок «Показывать в меню».
- **Новое фото**: Медиа → загрузить → «Копировать URL» → вставить у блюда.
- **Забыт пароль**: другой ADMIN меняет пароль в «Пользователях», либо на сервере:
  `SUPERADMIN_EMAIL=... SUPERADMIN_PASSWORD=... npm run superadmin`.
