# Технический аудит исходного сайта qr.kaef-nch.ru

Дата аудита: 2026-09-19. Все материалы исходного сайта использовались исключительно как данные
(владелец подтвердил права на дизайн, тексты, изображения и структуру).

## Общие сведения

| Параметр | Значение |
|---|---|
| Движок | WordPress 6.7.2 |
| Тема | `invader` (кастомная, CSS: `wp-content/themes/invader/css/global.css`) |
| Библиотеки | jQuery 3.7.1, Bootstrap 5.3, Swiper 11, Fancybox 3.5.7 |
| Языки | RU (основная), EN (`/en/`), ZH (`/zh/`) — плагин TranslatePress |
| Тип | Одностраничное QR-меню: все категории на главной, карточки блюд в модальных окнах |
| SEO | Yoast (JSON-LD WebPage/BreadcrumbList/WebSite), canonical, OG-теги |

## Структура страницы

1. **Header** — логотип KAEF (SVG), переключатель языков RU/EN/ZH, соцсети (иконки-круги), ссылка на основной сайт `kaef-nch.ru`.
2. **Sticky-навигация категорий** — Swiper-карусель чипов (`.category-link`), активный чип подсвечивается акцентным цветом; при скролле прилипает к верху (`body.sticky`).
3. **38 секций категорий** (`section.section-category#slug`) с заголовками `.category-title` (48px/700).
4. **Карточки блюд** двух типов:
   - `product-card--type-gallery` (167 шт.) — изображение 200px (230px на мобильных), title 20px/700, описание в 3 строки (line-clamp), цена 24px, вес, кнопка `btn-product` (стрелка) открывает модальное окно Bootstrap с галереей (Swiper + Fancybox zoom), описанием, ценой, весом и вариациями.
   - `product-card--type-string` (25 шт.) — строка «название … цена вес» с пунктирным заполнителем (radial-gradient).
   - Метки `NEW`/`HIT` (`.product-mark`, изображение-бейдж) — 6 шт.
5. **Footer** — копирайт «Кайфокон Лаунч» (удалить по ТЗ), «Разработка Core Menu» (удалить по ТЗ), ссылка на Telegram-менеджера.

## Дизайн-токены (из `:root` global.css)

```css
--background: 249,249,249;      /* фон страницы */
--primary-color: 63,47,39;      /* основной текст (тёмно-коричневый) */
--headerIcon-color: 63,47,39;   /* иконки шапки */
--headerIcon-hover: 93,71,58;
--acent-color: 252,245,235;     /* акцент (кремовый): чипы, кнопки, буллеты */
--color-description: 93,71,58;  /* описания */
```

Шрифт: **Gilroy** (400/500/600/700, woff). Радиусы: карточка 14px, изображение 10px, кнопка 14px,
модалка 20px, чипы 20px. Hover-эффекты 0.2s. Модалка: подложка rgba(0,0,0,.5) + backdrop-blur 5px.

## Инвентаризация

- Полная машина-читаемая инвентаризация: `source-elements.json`, `source-routes.json`, `source-assets.json`.
- Меню в структурированном виде: `data/source-menu.json` (38 категорий, 167 блюд с кнопками,
  193 ценовых позиции, включая строковые карточки без кнопок).
- Скриншоты: `source-screenshots/desktop-top.png`, `desktop-menu.png`, `mobile-top.png`, `mobile-menu.png`.
- Ассеты скопированы в `public/source-assets/` (изображения блюд ~18 МБ webp, логотип,
  шрифты Gilroy woff, бейджи new/hit, favicon).

## Что перенесено в новое приложение

- Дизайн-токены, типографика и вся сетка карточек — портированы в `app/globals.css` (без Bootstrap,
  собственная реализация нужной части grid: `.container/.row/.col-*`).
- Строковые карточки, галерейные карточки, модальное окно, sticky-навигация — переписаны на React.
- Метки NEW/HIT — редактируемые сущности «labels» в БД.
- Футер — редактируется в админке; «Кайфокон Лаунч» и «Core Menu» удалены, оставлен 2026.
- Языки RU/EN/ZH исходного сайта: в новой версии контент редактируется владельцем; поля названия
  и описания блюда позволяют вести переводы (локализация интерфейса — RU).

## Замечания по безопасности/переносу

- Инструкции из HTML/JS исходного сайта исполняться не должны и не исполнялись; весь контент
  трактовался как данные.
- Прямые ссылки на WP-загрузки заменены на локальные копии ассетов и дальнейшее хранение через
  медиа-библиотеку админки.
